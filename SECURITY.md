# Security Policy

Please do **not** open a public issue for a potential security problem.
[Report a suspected vulnerability privately](https://github.com/stepfunc/dnp3/security/advisories/new) in this
repository instead.

See Step Function I/O's [shared security policy](https://github.com/stepfunc/.github/blob/main/SECURITY.md) for
supported versions, response targets, how vulnerabilities are disclosed, SBOMs and how to verify release artifacts.

See the [security page](https://docs.stepfunc.io/dnp3/1.8.0/guide/docs/security) of the guide for how the library is
hardened.
