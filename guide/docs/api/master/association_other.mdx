You can perform other miscellaneous operations on an association, including:

* Performing ad-hoc (i.e., one time) read requests
* Synchronizing the outstation's time
* Performing warm/cold restarts
* Initiating link status requests to an outstation

You can find details about these operations in the language-specific API docs.

## Freezing counters

A master asks the outstation to freeze its counters by sending a request with a freeze function code and the counters it
applies to. The outstation copies each counter to its frozen counter, and can also clear the counter or freeze it on a
schedule. The example masters can freeze all the counters at once, freeze and clear them, or freeze them once a day:
