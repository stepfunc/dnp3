This guide is the primary documentation for Step Function I/O's DNP3 [library](https://github.com/stepfunc/dnp3). Here you'll find:

* Which parts of DNP3 the library implements
* How to use the library's Application Programming Interface (API)
* How the API maps to DNP3 concepts
* How to get pre-built binary distributions of the library for supported languages

API reference for each language: <a href={`https://docs.stepfunc.io/dnp3/${sitedata.version}/rust/dnp3/`}>Rust</a> · <a href={`https://docs.stepfunc.io/dnp3/${sitedata.version}/c/dnp3_8h.html`}>C</a> · <a href={`https://docs.stepfunc.io/dnp3/${sitedata.version}/cpp/namespacednp3.html`}>C++</a> · <a href={`https://docs.stepfunc.io/dnp3/${sitedata.version}/java/`}>Java</a> · <a href={`https://docs.stepfunc.io/dnp3/${sitedata.version}/dotnet/namespacednp3.html`}>.NET</a> (also under **API docs** in the navbar).

[Example programs](../examples/summary.mdx) in each language demonstrate the most common API features.

## IEEE-1815

This guide covers many DNP3 concepts but is not a replacement for the standard. If you're developing a DNP3 product, the standard is indispensable. Purchase it from the [DNP3 Users Group](https://dnp.org) or [IEEE](https://standards.ieee.org/standard/1815-2012.html).
