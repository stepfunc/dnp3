## Conformance Testing

Every release of the outstation passes the DNP3 IED Certification Procedure published by the DNP Users Group. CI runs
two revisions of it, using [dnp3c](https://github.com/stepfunc/dnp3c), our implementation of the procedures:

* Revision 3.1 rev 1 (2022), which covers subset levels 1 to 3. We run it at level 3.
* Revision 2.7 (2016), which covers subset level 2.

Both revisions must pass before a release is published, and they also run on a weekly schedule and on demand. Some
procedures don't apply to this configuration, such as the network and output event tests. We use these procedures to
augment our own unit and integration tests.

:::note
The DNP Users Group only certifies outstation devices as conforming to the specification, not libraries. Contact Step
Function I/O if you would like to engage us to conduct conformance testing for your outstation product.
:::

## Subset Levels

DNP3 defines four subset levels of interoperability:

* **Level 1** is the minimum functionality that a master or outstation must implement to be DNP3 compliant, intended for
  a small field device.
* **Level 2** adds function codes and objects to support a simple RTU or data concentrator.
* **Level 3** adds more, most notably enabling and disabling unsolicited reporting, to support complex RTUs and
  concentrators.
* **Level 4** adds rarely used features, such as floating-point analog variations, double-bit binary inputs, and device
  attributes.

Features like file transfer, datasets, and secure authentication don't belong to any subset level.

### Current Support: Level 3

The library is Level 3 compliant for both master and outstation, and already supports most of Level 4, along with
features outside the subset levels:

| Feature                   | Objects                                                  | Level |
|---------------------------|----------------------------------------------------------|:-----:|
| Device attributes         | Group 0                                                  |   4   |
| Double-bit binary inputs  | Groups 3 and 4                                           |   4   |
| Floating-point AI/AO      | Float and double variations in groups 30, 32 and 41      |   4   |
| Analog input deadbands    | Group 34                                                 |   4   |
| BO/AO events              | Groups 11 and 42                                         |   4   |
| Event class assignment    | ASSIGN_CLASS                                             |   4   |
| LAN time synchronization  | Group 50 variation 3                                     |   4   |
| Self-address support      | Link layer                                               |   4   |
| Octet strings             | Groups 110 and 111                                       |   -   |
| Master file transfer      | Group 70: read and write files, file info, directories  |   -   |

### Future Support

The library will be Level 4 compliant once the outstation supports binary and analog output command events (groups 13
and 43).
