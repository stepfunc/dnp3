DNP3 defines four subset levels of interoperability:

* `Level 1`: This is the minimum functionality that a master or outstation must implement to make it DNP3 compliant. Functionality will be quite basic and is only intended for a small field device.
* `Level 2`: This adds several function codes and objects in order to support a simple RTU or data concentrator.
* `Level 3`: This adds additional function codes and objects, most notably enable/disable of unsolicited reporting, in order to support complex RTUs/concentrators. 
* `Level 4`: This adds rarely-used features, such as floating-point analog variations, double-bit binary inputs, and device attributes.
Features like file transfer, datasets, and secure authentication do not belong to any subset level.


### Current Support: Level 3

Our library is currently `Level 3` compliant for both master and outstation. `Level 4` compliance is planned for a future release. We already support a number of `Level 4` features, along with features outside subset levels:

| Feature                   | Objects                                                 |   Level    |
|---------------------------|---------------------------------------------------------|:----------:|
| Device Attributes         |  Group 0                                                |     4      |
| Double-bit Binary Inputs  |  Groups 3 & 4                                           |     4      |
| Floating-point AI/AO      |  Float/double variations in groups  30, 32, and 41      |     4      |
| Analog Input Dead-bands   |  Group 34                                               |     4      |
| BO/AO events              |  Groups 11 & 42                                         |     4      |
| LAN time-synchronization  |  Group 50 Var 3                                         |     4      |
| Self-address support      |  (link layer)                                           |     4      |
| Octet strings (g110/111)  |  Groups 110 and 111                                     |     -      |
| Master File Transfer      |  Group 70 - read file, get file info, read directory    |     -      |

### Future Support

The library will be level 4 compliant when we add AO/BO command events (groups 13 & 43).

## Conformance Testing

The DNP3 User Group publishes the conformance test procedures for outstations, the DNP3 IED Certification Procedure. CI runs two revisions of it against the outstation, using [dnp3c](https://github.com/stepfunc/dnp3c), our implementation of the procedures:

* Revision 3.1 rev 1 (2022), which covers subset levels 1 to 3. We run it at level 3.
* Revision 2.7 (2016), which covers subset level 2.

Some procedures are disabled in this configuration, such as the network tests in section 9 and the output event tests in section 10. Each report gives the reason for every procedure it skips. We use these procedures to augment our own unit and integration tests.
